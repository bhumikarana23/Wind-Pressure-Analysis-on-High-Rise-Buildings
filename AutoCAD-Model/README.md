# AutoCAD – High-Rise Building Geometry Development

## Overview

This folder contains the building geometry developed using AutoCAD for the academic project **Wind Pressure Analysis on High-Rise Buildings Under Extreme Wind Conditions**.

The geometric model serves as the foundation for the subsequent Computational Fluid Dynamics (CFD) simulations conducted in ANSYS.

## Work Completed

- Developed the high-rise building geometry using AutoCAD.
- Prepared the building model for computational wind analysis.
- Established the geometric configuration required for CFD simulation.
- Organised the model files and screenshots for project documentation.

## Software Used

- AutoCAD
