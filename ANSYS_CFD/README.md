# ANSYS – Computational Fluid Dynamics (CFD) Analysis

## Overview

This folder contains the computational simulation work carried out using ANSYS for investigating wind flow behaviour and pressure distribution around a high-rise building.

The CFD analysis forms a major part of the project, focusing on understanding the interaction between wind flow and building geometry under specified simulation conditions.

## Work Completed

- Prepared the computational model for wind flow analysis.
- Configured the CFD simulation under specified boundary and simulation conditions.
- Performed numerical simulations using ANSYS.
- Generated simulation outputs for examining airflow behaviour and pressure distribution.
- Exported relevant simulation visualisations for further analysis.

## Software Used

- ANSYS Fluent
- Computational Fluid Dynamics (CFD)
